⚖️ 1. מודל השקעות ערך (Fundamental Value Model)

מיועד למשקיעים לטווח ארוך המחפשים חברות רווחיות, יציבות ומתומחרות בחסר (Under-valued) מתוך מדדי הליבה.

Value_Score = ( (1 / P/E_Ratio) * 40% ) + ( Profit_Margin * 30% ) + ( Dividend_Yield * 30% )
  • מכפיל רווח (P/E): עדיפות למכפילים נמוכים (מניות זולות יחסית לרווחיותן).
  • שולי רווח (Profit Margin): סינון של חברות עם שולי רווח נקי מעל 5%.
  • תשואת דיבידנד (Dividend): תגמול לחברות המחלקות תזרים מזומנים שוטף לבעלי המניות.

⚡ 2. מודל מומנטום ותנופה טכנית (Quantitative Momentum Model)

מיועד למסחר לטווח קצר-בינוני, מזהה פריצות מחיר, כניסת כסף מוסדי וחוזק יחסי (Relative Strength).

Momentum_Score = ( Monthly_Return * 50% ) + ( Weekly_Return * 30% ) + ( Volume_Spike * 20% )
  • תשואה חודשית ושבועית: מדידת קצב עליית המחיר (Rate of Change).
  • פאלס נפח מסחר (Volume Pulse): זיהוי כניסת מחזורי מסחר חריגים (מעל ממוצע 30 יום) המעידים על עניין מוסדי.
  • סינון מגמה (Trend Filter): אימות שהמחיר מעל ממוצע נע 50 יום (50-Day SMA).
  • RSI (Relative Strength Index): מניעת כניסה למניות הנמצאות בקניית יתר קיצונית (RSI > 80).

📊 3. מנוע הבקטסטינג ומדדי ביצוע מוסדיים

Sharpe Ratio: יחס התשואה העודפת לתנודתיות הכללית. מעל 1.0 = מצוין.
Sortino Ratio: התמקדות בתנודתיות שלילית בלבד (עונש רק על ירידות).
Max Drawdown: אחוז הנפילה המקסימלי שנרשם מהשיא לשפל בתקופה.
Alpha & Beta: תשואה עודפת מעל השוק (אלפא) ורגישות לתנודות השוק (ביתא).
